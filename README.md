## Conhecimentos

Ao longo da minha formação acadêmica e dos meus estudos independentes, venho desenvolvendo conhecimentos em diferentes áreas da computação e do desenvolvimento de software.

### Programação

Tenho conhecimentos em **C**, principalmente relacionados à programação estruturada, lógica de programação, estruturas de controle, funções, vetores e fundamentos de algoritmos.

Com **Java**, estudo conceitos de **Programação Orientada a Objetos**, incluindo classes, objetos, métodos, encapsulamento, herança e organização de aplicações.

Também utilizo **Python** em atividades de programação, análise de dados e experimentação com diferentes bibliotecas e técnicas computacionais.

### Desenvolvimento Web

Possuo conhecimentos em **HTML e CSS** para estruturação e estilização de páginas web.

Também tenho contato com **JavaScript**, utilizado para adicionar funcionalidades e interatividade às aplicações web, e com **PHP**, principalmente no desenvolvimento de aplicações web no lado do servidor.

### Banco de Dados

Tenho conhecimentos em **MySQL**, trabalhando com bancos de dados relacionais, tabelas, relacionamentos, consultas SQL e manipulação de dados.

Também possuo contato com **SQLite**, utilizado principalmente em aplicações que necessitam de armazenamento local.

### Dados e Computação

Utilizo **Python e Jupyter Notebook** para desenvolvimento de experimentos, análise de dados e exploração de diferentes técnicas computacionais.
