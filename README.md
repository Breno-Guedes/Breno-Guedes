## Sobre mim

Olá! Sou **Breno de Souza Guedes**, estudante de **Análise e Desenvolvimento de Sistemas (ADS)** no **Instituto Federal do Piauí (IFPI) – Campus Corrente**. Tenho grande interesse em desenvolvimento de software, resolução de problemas e aprendizado prático. Busco transformar conceitos acadêmicos em aplicações reais, com foco atual em **Dart**, **Flutter** e **Spring Boot** para o desenvolvimento de soluções web e mobile.
